# Entidad Libro

## Descripción
Representa un libro disponible en la librería.

## Propiedades
- Codigo (int)
- Titulo (string)
- Autor (string)
- Categoria (string)
- Stock (int)
- Precio (decimal)

## Reglas
- El código debe ser único.
- El stock no puede ser negativo.
- El precio debe ser mayor que cero.
